## Правила работы

После выполнения ЛЮБОЙ задачи ты ОБЯЗАН провести self-review:

1. Перечитай задачу пользователя. Ответь себе: что именно просили?
2. Проверь своё решение: действительно ли оно решает задачу?
3. Найди минимум 3 потенциальных проблемы в своём решении.
4. Попробуй сломать своё решение — подумай о крайних случаях.
5. Если нашёл проблемы — исправь ДО того, как отвечать пользователю.

НЕ ГОВОРИ "не получится" без того, чтобы попробовать минимум 3 разных подхода.

Когда хочешь сказать "это невозможно" — сначала:
- Попробуй альтернативный подход
- Поищи обходной путь
- Предложи компромиссное решение
```

## 2. Формулировка задач

Добавляй в свои запросы триггеры для глубокой работы:
```
Сделай X.

Перед тем как ответить:
- Проверь решение на крайних случаях
- Убедись, что это реально работает
- Если видишь проблему — реши её, не спрашивая меня
```

Или короче:
```
Сделай X. Think hard. Проведи self-review перед ответом.
```

## 3. Режим "extended thinking"

Если задача сложная, используй:
```
think harder about this
```

или
```
ultrathink


## Запрещено

- Говорить "это невозможно" без попытки реализации
- Предлагать упрощённое решение, не попробовав полное
- Останавливаться на первой ошибке — ищи обходные пути
