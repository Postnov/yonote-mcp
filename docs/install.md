# Инструкция по установке Mereal Reports

## Требования

- PHP 8.0+ с расширениями: `pdo_sqlite`, `sqlite3`, `curl`, `json`
- Веб-сервер: Apache (с `mod_rewrite`) или Nginx
- Хостинг или VPS с поддержкой PHP

---

## 1. Загрузка файлов

Скопируй все файлы проекта на сервер в нужную директорию (например, `/public_html/reports/`).

**Структура проекта:**
```
reports/
├── api/              # PHP-бэкенд
│   ├── auth.php
│   ├── auth_middleware.php
│   ├── db.php
│   ├── projects.php
│   ├── proxy.php
│   ├── settings.php
│   └── users.php
├── css/
│   └── style.css
├── data/             # База данных (создаётся автоматически)
│   └── .gitkeep
├── docs/
├── fonts/
├── images/
│   └── mereal-logo.svg
├── js/               # JS-модули
│   ├── ai-agent.js
│   ├── auth.js
│   ├── config.js
│   ├── event-bus.js
│   ├── main.js
│   ├── markdown-processor.js
│   ├── project-api.js
│   ├── router.js
│   ├── tool-executor.js
│   ├── ui.js
│   ├── user-api.js
│   ├── yonote-client.js
│   └── ...

```

> ⚠️ **Не загружай** файл `data/app.db` при первой установке — он создаётся автоматически при первом запуске.

## 2. Права доступа

Папка `data/` должна быть доступна для записи PHP-процессу:

```bash
chmod 755 data/
```

Если база уже создана:
```bash
chmod 644 data/app.db
```

---

## 3. Настройка веб-сервера

### Apache

Файл `.htaccess` уже находится в корне проекта — он настраивает:
- Правильный MIME-тип для JS-модулей
- Защиту папки `data/` от прямого доступа

Убедись, что в конфигурации Apache разрешён `AllowOverride All` для директории проекта.

### Nginx

Добавь в блок `server`:

```nginx
location ~* \.js$ {
    add_header Content-Type application/javascript;
}

location /data/ {
    deny all;
}
```

## 4. Первый запуск

1. Открой сайт в браузере (например, `https://example.com/reports/`)
2. Появится экран **«Первый запуск»** — создай аккаунт администратора:
   - Имя
   - Email
   - Пароль
3. После создания аккаунта произойдёт автоматический вход

---

## 5. Настройка API-ключей

После входа перейди в **Настройки** (пункт меню сверху):

| Поле | Описание |
|------|----------|
| **Yonote API Token** | Токен API из личного кабинета Yonote (`Настройки → API`) |
| **Yonote Base URL** | URL API Yonote. По умолчанию: `https://app.yonote.ru/api` |
| **DeepSeek API Key** | API-ключ DeepSeek для генерации отчётов (`platform.deepseek.com`) |

Нажми **Сохранить** — страница перезагрузится.

---

## 6. Создание проекта

1. На странице **Проекты** нажми **+ Новый проект**
2. Укажи название проекта
3. Заполни ссылки на страницы Yonote:
   - **Страница с тегами** — страница в Yonote, где каждая строка начинается с `#` (список тем для отчётов)
   - **Страница для поиска** — корневая страница, по подстраницам которой будет вестись поиск
   - **Страница для отчётов** — страница, внутри которой будут создаваться новые отчёты
4. Нажми **Сохранить**

> Ссылки можно вставить как URL страницы из браузера — система автоматически извлечёт ID документа.

---

## 7. Добавление пользователей (опционально)

Перейди в **Пользователи** (пункт меню, только для администратора):

1. Нажми **+ Добавить пользователя**
2. Укажи имя, email, пароль и роль (`admin` или `user`)
3. Отметь галочками проекты, к которым пользователь получит доступ
4. Нажми **Сохранить**

Пользователи с ролью `user` видят только назначенные проекты и не могут менять настройки.

---

## 8. Использование

1. Открой проект из списка
2. Система загрузит список тем (тегов) со страницы Yonote
3. Выбери одну или несколько тем
4. Нажми **Создать отчёт**
5. Система обойдёт все подстраницы, найдёт секции с нужными заголовками и создаст отчёт в Yonote

## Устранение неполадок

### 404 на CSS/JS файлы
- Проверь, что файлы загружены в правильные папки
- Убедись, что `.htaccess` загружен и `mod_rewrite` включён

### Ошибка при входе (401)
- База данных на сервере отдельная от локальной
- Если первый запуск — удали `data/app.db` на сервере и пройди setup заново

### Теги не загружаются
- Проверь Yonote API Token в Настройках
- Убедись, что на странице тегов каждая тема начинается с `#`

### Ошибки PHP (500)
- Проверь наличие расширений: `php -m | grep -E 'sqlite|curl|pdo'`
- Убедись, что папка `data/` доступна для записи
