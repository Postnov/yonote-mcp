## Где остановились
**Дата:** 2026-02-17

`extract_sections` теперь рекурсивно обходит ВСЕ уровни вложенности через `fetch_all_descendants()` (BFS). Раньше искал только прямых детей (1 уровень), теперь находит страницы на любой глубине (Авгодом → Интерьер → 1 этаж, Гости). **164 теста, все проходят.**
